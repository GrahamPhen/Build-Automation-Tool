# Goals

Make natural-looking, hand-built Minecraft timelapse Shorts: a character finds a good spot, shapes the
ground and builds a whole schematic block by block while Flashback records, ready to cut into a Short.

Reference Shorts (the look we are matching):
- https://www.youtube.com/shorts/_q3Fv4zii8w
- https://www.youtube.com/shorts/g1a-IWkuYnQ
- https://www.youtube.com/shorts/GRBjhricyA4

Hard rules:
1. Every build block is placed by the character with a real click. No printer, no `/setblock`/`/fill`
   of build blocks, no Litematica ghost, chat text or mod overlays on camera.
2. Terraforming is done by hand, on camera, and blends into the surroundings.
3. Runs unattended from one command (or the launcher's `-Build`) to a saved take.
4. Never save an empty or stalled take.
